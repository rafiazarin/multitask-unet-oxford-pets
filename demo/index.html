    About the model

    One network predicts both a pet/background mask and one of the 37 breeds in the Oxford-IIIT Pet dataset. On the held-out test set (1,109 images): Pet IoU 0.924, breed accuracy 92.4%. The ONNX file used here was checked against the original PyTorch model on that full test set before release.

    Limitations

    • It only knows 37 breeds. For any other breed, or an image with no pet, it still returns one of the 37. It does not reject unrelated images yet.
    • The mask is predicted at 224×224 and scaled up to your image, so edges are soft.
    • The browser resizes your photo slightly differently from the Python pipeline used for evaluation, so results can differ a little from the reported test setup.
